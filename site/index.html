      How it works

      Every night a headless browser opens each app logged-out and downloads the same JavaScript any visitor gets, plus the code chunks those files point to. Nothing behind a login, nothing decompiled.

      Every human-readable string is added to a ledger. The first night only records a baseline. After that, a string that has never appeared before is a clue: interface copy, an experiment name, a feature flag.

      Claude reads the night's clues, throws away the noise, and writes a forecast for each real feature: a short product spec, a deadline and a probability. Evidence has to quote the code exactly, or it is dropped.

      Each night open forecasts are checked against the company's official release notes. Shipped before the deadline is a hit; after it is late; nothing by twice the window is a miss. Features that were already public are voided, not counted.

      The headline score is the Brier score of each forecast as first published: the squared gap between the stated probability and what happened. Zero is perfect. Saying 50% every time scores 0.25.
